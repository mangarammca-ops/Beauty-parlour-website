# 💄 Beauty Parlour Website

A stylish, elegant, and modern Beauty Parlour Website designed to showcase beauty services, makeup styles, skincare treatments, and professional salon facilities.

## 🌸 About The Project

This Beauty Parlour Website is created using HTML, CSS, and JavaScript. It features a premium theme with an attractive layout, beautiful images, smooth animations, and a user-friendly interface.

The website helps customers explore beauty services, view makeup collections, and contact the parlour for appointments.

## ✨ Features

- Attractive Home Page
- About Us Section
- Professional Beauty Services
- Bridal Makeup Collection
- Hair Styling & Hair Care
- Facial & Skincare Treatments
- Nail Art & Mehndi Designs
- Beautiful Image Gallery
- Customer Testimonials
- Appointment Booking Form
- Contact Information
- Responsive Website Design

## 🛠️ Technologies Used

- HTML5 – Website Structure
- CSS3 – Styling & Layout
- JavaScript – Interactive Features

## 🚀 How To Run The Project

1. Download or clone this repository.
2. Extract the project folder.
3. Open the folder in VS Code.
4. Open `index.html` in your browser.
5. Explore the Beauty Parlour Website.
